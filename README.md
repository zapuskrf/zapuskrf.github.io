# Запуск — zapuskrf.github.io

Ежедневная лента о новых производствах, технологиях и инфраструктуре России.
Короткие посты публикуются в Telegram-канале, полные статьи — на этом сайте.

## Как устроена публикация

1. Каждое утро Claude собирает выпуск и открывает Pull Request с новыми файлами в `content/news/`.
2. Редактор читает статьи прямо в Pull Request, при необходимости правит или удаляет файлы.
3. Нажатие **Merge** = одобрение. Новости встают в очередь и выходят **по одной, по расписанию** в течение дня.

### Расписание

- Время выхода задаётся в `site.yml` → `publish_times` (московское время), по умолчанию 09:00, 11:00, 13:00, 15:00, 17:00, 19:00.
- Новость с `order: 1` выходит в первое время, `order: 2` — во второе и т.д. Если новостей больше, чем времён, лишние идут следом за последней.
- Своё время для отдельной новости: `publish_at: "14:30"` в её файле.
- Каждые 15 минут GitHub Actions проверяет очередь. Если время новости наступило, она появляется на сайте, а после этого её пост уходит в Telegram. За один раз выходит одна новость, поэтому даже выпуск, одобренный с опозданием, расходится постепенно (раз в 15 минут), а не пачкой.
- Выпущенные новости записываются в `content/published.txt` (ведётся автоматически). Посмотреть план: `python scripts/release.py --plan`.
- GitHub запускает задачи по расписанию с задержкой до 10–20 минут, поэтому время выхода приблизительное.

Если не нажимать Merge, ничего не публикуется. Изменение уже опубликованной статьи обновляет сайт, но повторно в Telegram не отправляется.

## Формат статьи

Файл `content/news/ГГГГ-ММ-ДД-slug-latinicey.md`. Имя файла становится адресом: `/news/ГГГГ-ММ-ДД-slug-latinicey/`.

```markdown
---
title: В Калужской области запустили завод подшипников   # до 90 знаков
date: 2026-10-25              # дата выпуска
rubric: Промышленность        # Промышленность | Технологии и изобретения | Инфраструктура | Логистика | IT и связь
region: Калужская область
status: Запуск производства   # Введено в эксплуатацию | Запуск производства | Начало строительства | Патент / разработка | Официально объявленный проект
event_date: 2026-10-23
order: 1                      # порядок в выпуске (1 — главная новость дня)
lead: Одно-два предложения для карточки на главной.
telegram: |
  🏭 Заголовок поста
  2–3 предложения: что произошло, ключевая цифра, почему важно.
hashtags: "#промышленность #Калуга"
sources:
  - title: Минпромторг России — пресс-релиз
    url: https://minpromtorg.gov.ru/...
# draft: true      — не публиковать
# tg_skip: true    — опубликовать на сайте, но не в Telegram
---
Текст полной статьи в Markdown, разделы через `## Подзаголовок`.
```

Ссылка на статью добавляется в Telegram-пост автоматически — под словом «Подробнее...», без карточки-предпросмотра.

## Настройка

- `site.yml` — название, адрес сайта, Telegram-канал, рубрики и их цвета.
- Секрет `TELEGRAM_BOT_TOKEN` (Settings → Secrets and variables → Actions → Secrets) — токен бота.
- Переменная `TELEGRAM_CHANNEL` (там же → Variables), необязательно — например `@zapuskrf`.
- Settings → Pages → Source: **GitHub Actions**.
- Свой домен: впишите его в `domain` и поменяйте `url` в `site.yml`.

## Локальная сборка

```bash
pip install markdown pyyaml jinja2
python build.py           # результат в _site/ (только выпущенные новости)
python build.py --all     # вместе с теми, что ждут выхода
```
