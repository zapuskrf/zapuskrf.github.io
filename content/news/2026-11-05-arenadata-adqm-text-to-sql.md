Российский разработчик платформ для работы с данными Arenadata выпустил версию аналитической СУБД Arenadata QuickMarts (ADQM) 26.8.2.7 со встроенным сервисом Text-to-SQL. Он позволяет формулировать запросы к данным на естественном языке и получать в ответ готовый SQL-код.

## Что запустили

Согласно документации Arenadata, сервис Text-to-SQL доступен в редакции Enterprise начиная с версии 26.8.2.7. Он преобразует текстовый вопрос пользователя в SQL-запрос типа SELECT для чтения данных кластера ADQM. Сервис устанавливается из интерфейса Arenadata Cluster Manager и пока имеет статус технологического превью — разработчик не рекомендует использовать его в промышленной эксплуатации.

В основе сервиса — дообученная языковая модель семейства Qwen, которая запускается локально на одном из хостов кластера через llama.cpp. Благодаря этому вопросы пользователей, схема базы и сами данные не передаются во внешние облачные сервисы.

После установки в СУБД появляется функция text2sql: она возвращает текст запроса либо объяснение, почему запрос сформировать не удалось. Вызывать её может любой пользователь базы без дополнительных привилегий. В инструменте ADQM Notebook достаточно ввести вопрос в SQL-ячейку и нажать значок ИИ. Также предусмотрен HTTP API.

Администратор может ограничить, к каким базам и таблицам у модели есть доступ, и настроить, проверять ли сгенерированный запрос через EXPLAIN перед выдачей пользователю.

## Кто реализовал

Arenadata — российская компания, разрабатывающая платформу для хранения и обработки больших данных. ADQM — колоночная аналитическая СУБД из её линейки, предназначенная для быстрых запросов к большим массивам данных и используемая для построения витрин данных.

## Значение для отрасли и региона

Генерация SQL по запросу на естественном языке упрощает работу с данными для бизнес-пользователей, не владеющих языком запросов. Локальное размещение модели важно для банков, госсектора и промышленности, где передача данных внешним ИИ-сервисам ограничена требованиями безопасности. Появление такой функции в отечественной СУБД расширяет возможности замены зарубежных аналитических платформ.

## Что дальше

Сервис выпущен в статусе технологического превью; переход к промышленной версии будет зависеть от результатов тестирования у заказчиков. Разработчик предусмотрел механизм обратной связи по качеству сгенерированных запросов через API.
